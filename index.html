03 / LEARN

Quick debugging guide

A few habits that save time
01

Read the first error

Start with the earliest error in the console. Later errors may be consequences of the first one.

02

Check the line number

Inspect the reported line and the lines immediately before it for missing brackets or punctuation.

03

Test one change

Make one small change at a time, then run your code again to confirm what fixed the problem.
